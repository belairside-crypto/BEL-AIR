# BEL AIR — Urban Luxury

Sitio web estático listo para abrir localmente.

## Probar en Visual Studio Code

1. Extrae el ZIP.
2. Abre la carpeta `BEL_AIR_urban_luxury` en Visual Studio Code.
3. Abre `index.html` en el navegador. 
4. Para una experiencia de desarrollo más cómoda, instala la extensión **Live Server** y usa "Open with Live Server".

## Estructura

- `index.html` — página completa.
- `styles.css` — diseño, responsive, efectos y transiciones.
- `script.js` — loader, menú, carrito, vista rápida y formulario.
- `assets/campaign-01.jpg` — foto 1.
- `assets/campaign-02.jpg` — foto 2.
- `assets/campaign-03.jpg` — foto 3.
- `assets/ba-logo.png` — logo preparado para el loader.

## Nota

La página usa Google Fonts mediante `@import`. Si se abre completamente sin internet, el sitio seguirá funcionando pero el navegador puede usar las fuentes de respaldo.
